OneClass 背单词助手 · 常见问题 / 自助排查
=============================================

  遇到问题先按这里找；找不到再双击 诊断.cmd，把 diag_report.txt 发给卖家。


零、三句话版本
------------------------------------------------------------
1. 启动后立刻变「已停止」 → 看第 1 条（声卡问题，最常见）
2. 页面一直 unknown / 不动 → 看第 3 条（识别区域没定位好）
3. 听写题答错/跳过 → 看第 2 条（录音设备或发音模板）


一、启动机器人后几秒就「已停止」
------------------------------------------------------------
先看界面日志或 wordbot.log 最后几行。

情况 A：出现「退出码 3221226356」或「常驻录音启动失败：integer ...
does not fit 'unsigned short'」
    原因：你的声卡驱动和录音库（soundcard）不兼容，程序在打开
          回环录音时崩溃。这个在部分笔记本/声卡上会出现。
    解决（最快）：用记事本打开本目录的 config.yaml，找到
          audio_capture: true
       改成
          audio_capture: false
       再找到
          audio_templates: true
       改成
          audio_templates: false
       保存后重新双击 启动界面.cmd。
       影响：背单词、选择题正常；听写题会跳过（自动点「我不会」）。

    想听写也能用：
      1) 双击 安装.cmd，看最后列出的「音频设备」，找到 loopback=True 那个
      2) config.yaml 里：
         audio_capture: true
         audio_loopback_name: 这里填那个设备名（一字不差）
      3) 保存 → 双击 诊断.cmd，看到「录音正常」就成功了

    还不行就装虚拟声卡 VB-CABLE（免费）：
      1) https://vb-audio.com/Cable/ 下载安装，重启
      2) 系统声音输出选 CABLE Input
      3) config.yaml:
         audio_loopback_name: CABLE Output (VB-Audio Virtual Cable)

情况 B：出现「ModuleNotFoundError」或「依赖没装好」
    解决：双击 安装.cmd 重新装依赖。还不行说明 Python 版本不对。

情况 C：出现「当前 Python 是 3.x，依赖是按 3.13 装」
    解决：装 Python 3.13（https://www.python.org/downloads/release/python-3139/）
         装的时候勾选 Add python.exe to PATH，装完重新双击 安装.cmd。

情况 D：日志里什么都没有
    说明旧版本把报错丢掉了。请换最新安装包，或双击 诊断.cmd。


二、听写题不对 / 一直跳过 / 提示「录音是静音」
------------------------------------------------------------
1. 双击 诊断.cmd，看 [3.5] 发音模板：
   - 「来源机器」不是你的机器码 → 模板已自动停用，属正常（不影响使用）
   - 想让听写更准：删掉本目录的 audio_templates.json，让它在本机重新积累
2. 看 [4] 里是否「录音正常（RMS=…）」：
   - RMS=0.0000 → 系统静音或输出设备不对：调大音量，或按第 1 条情况 A 的
     「想听写也能用」设置 audio_loopback_name
3. config.yaml 里 dictation_mode 保持 whisper，不要改。


三、页面一直「unknown」，或点了没反应 / 卡住
------------------------------------------------------------
这是「识别区域」没框好，或小程序被别的窗口挡住。

1. 把「一课英语」小程序窗口露出来，别最小化、别被浏览器挡住
2. 双击 启动界面.cmd →「1. 扫描窗口」→ 选中 OneClass
3. 点「2. 预览并确认定位」→ 看预览图里是不是只有小程序内容
4. 点「保存配置」→「预检」→「▶ 启动机器人」

如果启动时日志出现「识别区域超出屏幕」：
    说明你屏幕比原来设的小，重新做上面 2~4 步即可（程序也会自动收进屏幕）。


四、怎么改 config.yaml（不会改错的 5 条规矩）
------------------------------------------------------------
1. 用记事本打开（右键 → 打开方式 → 记事本）
2. 只改「冒号后面的值」，键名一个字都别动：
       audio_capture: false        ✅
       audio capture: false        ❌
       audio_capture:false         ❌（要空格）
       audio_capture：false        ❌（要用英文冒号）
3. 只有 region: 下面的数字是缩进的，其他键都顶格，别乱加空格
4. 保存时「保存类型」选「所有文件」，文件名必须是 config.yaml
   不要变成 config.yaml.txt
5. 改之前先复制一份 config.yaml 当备份，改坏了直接换回来

改完不用重装，重新双击 启动界面.cmd 即可。


五、这些键不要动
------------------------------------------------------------
  region                → 用界面「扫描窗口 → 预览确认定位」生成
  dictation_mode        → 保持 whisper
  whisper_model         → 保持 models/small.en
  input_backend         → 保持 win32
  fallback_points 下面   → 坐标是调好的

界面上点「保存配置」只改速度/模型/录音时长，不会覆盖你手改的
audio_capture、audio_loopback_name，可以放心点。


六、付费版（如果你买的是付费版）
------------------------------------------------------------
1. 查看剩余额度：双击 激活.cmd，窗口里显示「剩余额度」或「已解锁」
2. 额度用完：机器人会自动停止并提示充值
3. 充值：双击 激活.cmd → 扫对应金额的收款码 → 把「机器码」发给卖家
   → 收到激活码后粘贴到窗口里 → 点激活
4. 计费规则：3 元 = 500 词；15 元 = 全部 2862 词；
   同一个单词只扣一次（复习、重复出现都不再扣）
5. 换电脑/重装系统后机器码会变，需要重新找卖家换激活码


七、一键诊断
------------------------------------------------------------
双击 诊断.cmd，等 30 秒左右，会生成 diag_report.txt，里面有：
  [1] Python 版本
  [2] 依赖是否齐全
  [3] 配置 / 识别区域 / 屏幕尺寸 / 语音模型
  [3.5] 发音模板来源
  [4] 试启动 main.py 的结果（退出码 + 最后输出）

把这个文件发给卖家，能直接定位问题。


八、恢复默认配置
------------------------------------------------------------
1. 关掉程序
2. 删掉 config.yaml（或改名备份）
3. 双击 启动界面.cmd → 重新「扫描窗口 → 预览确认定位 → 保存配置」

注意：删掉 config.yaml 会丢掉识别区域和速度设置，需要重新定位。
